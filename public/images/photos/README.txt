Real photos go in this folder.

Every photo slot on the site shows a placeholder with the exact filename it
is waiting for, for example "hero-home.jpg". Drop a photo in here with that
name and it appears on the site automatically. Nothing in the code needs to
change.

Good sizes:
  Full-width hero photos ....... about 2400 pixels wide
  Photos inside a section ...... about 1400 pixels wide
  Small square photos .......... about 800 pixels wide

JPG is best for photographs. Keep each file under about 500 KB so pages load
quickly.
